**AppGlot** is an interactive, browser-based polyglot learning application designed to build foundational vocabulary across **English, German, French, and Spanish**. It features multi-language parallel translations, real-time native speech pronunciation via the Web Speech API, an interactive multiple-choice quiz engine, and persistent progress analytics.

## ✨ Key Features

- **4-Language Parallel Translation Grid**: View any word or phrase side-by-side in English (`en-US`), German (`de-DE`), French (`fr-FR`), and Spanish (`es-ES`).
- **Native Audio Speech Synthesis**: Hear accurate native pronunciations powered by browser `window.speechSynthesis` with language-specific locale detection.
- **Categorized Study Decks**:
  - *Greetings & Essentials*
  - *Numbers & Counting*
  - *Food & Dining*
  - *Travel & Directions*
  - *Essential Daily Verbs*
- **Interactive Quiz Challenge Mode**: Test retention with randomized multiple-choice questions, real-time scoring HUD, and instant visual feedback.
- **Mastery & Analytics Dashboard**: Tracks cards mastered vs. cards needing review with persistent client-side `localStorage`.
- **Full Keyboard Navigation**: Designed for fast power-user review with hotkey shortcuts.

## ⌨️ Keyboard Shortcuts

| Key | Action |
| :--- | :--- |
| <kbd>Space</kbd> | Flip / Toggle Translations Grid |
| <kbd>←</kbd> / <kbd>→</kbd> | Previous / Next Flashcard |
| <kbd>S</kbd> | Play Native Audio Pronunciation |
| <kbd>Q</kbd> | Launch Interactive Quiz Mode |

## 🛠️ Local Setup

No external dependencies or build tools required. AppGlot runs directly in any modern web browser:

```bash
# 1. Clone repository
git clone https://github.com/meha-1801-duggad/AppGlot.git
cd AppGlot

# 2. Open index.html in your browser
# On Windows:
start index.html

# On Mac:
open index.html
```
